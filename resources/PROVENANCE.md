# Происхождение ресурсов и сборщика

Код разбора Markdown, генерации DOCX и работы с OOXML перенесён из
[ispras/proceedings-md](https://github.com/ispras/proceedings-md), локальная
ветка `seqsan-paper-support`, коммит
`486c2bd9fc1dd29ba0b3d52b5d766226b79939d1`.
Эта ветка содержит доработки для статьи о SeqSan.
Исходный шаблон взят из `resources/isp-reference.docx` того же коммита.

В перенесённом коде изменены интерфейс запуска, работа с путями, нумерация,
обработка ошибок, рендер формул и проверки DOCX. Неиспользуемые пути через
Pandoc, LaTeXML и альтернативный генератор не включены.
Реквизиты образца и цветовое выделение шаблона сохранены.
Начальная страница изменена с 15 на 1.

`formulas.tex` содержит преамбулу и макросы формул статьи. Шрифты
`fonts/cmun*.otf` — Computer Modern Unicode из TeX Live 2026. Они распространяются
по SIL Open Font License 1.1, полный текст и уведомления об авторских правах
находятся в [fonts/OFL.txt](fonts/OFL.txt).

У исходной локальной копии `proceedings-md` не было файла LICENSE.
Перенос не добавляет новую лицензию на этот код или статью.

Пример `sample/sample.md` использует метаданные исходного примера `proceedings-md`.
Исходный пример сохранён как `sample/legacy-sample.md`. Пример TikZ и тестовые
зависимости рисунков самостоятельные; исходники статьи SeqSan сюда не включены.
